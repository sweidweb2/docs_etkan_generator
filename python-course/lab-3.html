Student Study Tracker

You are not solving 20 separate exercises. You build one console app. Each step adds a feature to the same program. Later steps reuse what you wrote earlier.

Phase 13
13 Runs, but wrong answer
Connects to Step 09: same progress feature, but the math is wrong. Python does not crash — you must spot the mistake yourself.

Required

  • Use a wrong formula like remaining = total - completed + 1
  • Run it and notice the output does not match reality
  • Explain why this is a logical error (not syntax, not runtime)

Code like remaining = total - completed + 1 does not crash — the result is wrong. No error message. That is a logical error.
