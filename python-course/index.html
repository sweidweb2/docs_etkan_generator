10 Debugging & exceptions

Know the kinds of errors, how to read a traceback, and how to handle them in Python.

Syntax

The code cannot run. Python stops before starting.

Runtime

The program starts, then crashes. Read the traceback.

Logical

It runs, but the answer is wrong. Trace the values.

reading tracebacks try except else finally raise

try / except catch runtime errors. else runs if nothing failed. finally always runs. raise throws an error on purpose.

11 · Data structures — how you store and organize data

Array / List

Store ordered data. Access by index. Example: [10, 20, 30]

String

Store and process text. Characters can be accessed by index.

Dictionary / Hash map

Store key → value. Fast lookup. Frequency counting and mappings.

Set

Store unique values. Fast membership checking. Removing or checking duplicates.

Stack

LIFO — last in, first out. Undo, parentheses, nested operations.

Queue

FIFO — first in, first out. Process things in arrival order.

Tuple

Ordered, immutable collection. Useful for fixed groups of values. Optional.

12 · Problem-solving patterns

Problem-solving patterns

Ways of thinking — approaches for solving problems efficiently.

Brute force

Try all possibilities. Usually the starting point.

Two pointers

Use two indexes instead of repeatedly scanning. Common with arrays and strings. Often O(n).

Sliding window

Maintain a moving range / window. Subarray and substring problems.

Hash map / frequency counting

Use a dictionary or set to avoid repeated searching. Counting, duplicates, lookup, Two Sum.

Binary search

Search a sorted space by repeatedly cutting it in half. O(log n).

Stack pattern

Use stack behaviour for nested or order-dependent problems. Parentheses, monotonic stack, undo.

Sorting + searching

Sort first to make a problem easier, then use pointers, binary search, or similar.

Prefix sum

Precompute cumulative values. Quickly calculate range sums.

Recursion / divide & conquer

Break a problem into smaller versions of itself. Trees, backtracking, divide-and-conquer.
