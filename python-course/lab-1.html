Lab 01 · Exercises 01–05

Exercises

Write each program in Python. Read values with input(), convert numbers with int() or float(), and print the result with print().
01 Swap two values

Write a program that swaps two values given by the user and displays the result.

02 Sum and average

Write a program that calculates the sum and the average of two integer values entered by the keyboard.

03 Age from year of birth

Write a program that calculates the age of a person whose year of birth is entered through the keyboard.

04 Circle — surface and perimeter

Write a program that calculates the surface and the perimeter of a circle whose radius is entered through the keyboard. Define pi = 3.14 as a constant.

05 (A + B)²

Write a program that calculates (A + B)². A and B are two variables entered through the keyboard. Use the function pow(x, a) from the math library, which calculates xa.

from math import pow  →  pow(A + B, 2)

06 Arithmetic progression

Write a program which calculates the last term and the sum of terms of an arithmetic progression (a series of consecutive numbers separated by the same deviation), knowing the first term a, the reason r, and the number of terms n.

Last term an = a + (n − 1) r
Sum of terms S = n / 2 × (2a + (n − 1) r)
07 Student average

Write a program that reads the name of a student and his three grades, then displays the average of the grades.

08 Invoice with tax

Write a program that asks for the unit price and quantity of an item, then displays an invoice in the following form:

Total price excluding VAT = ...
Tax = ...
Total price (tax included) = ...

The tax is worth 12.5%.

09 Rectangle from two points

A rectangle can be drawn from the knowledge of 2 points forming a diagonal. A point is defined by its coordinates (x, y).

Write a program that takes from the user the coordinates of these 2 points (Xa, Ya, Xb, Yb):

  1. Calculate the width of the rectangle
  2. Calculate the height of the rectangle
  3. Calculate the perimeter of the rectangle
  4. Calculate the surface of the rectangle
  5. Display all the information of the rectangle
