01 Solve ax² + bx + c = 0

Write a program that solves a polynomial of the second degree ax² + bx + c = 0. a, b and c are entered through the keyboard. Use sqrt(x) from the math library.

from math import sqrt

If a ≠ 0, the roots are calculated from the discriminant:

Discriminant Δ = b² − 4ac
If Δ > 0 — two real roots
x₁ = (−b + √Δ) / (2a)
x₂ = (−b − √Δ) / (2a)
If Δ = 0 — one repeated root
x = −b / (2a)
If Δ < 0 — two complex roots

i is the imaginary unit. Do not store the complex roots in variables — only display them.

x₁ = −b / (2a) + i · √(−Δ) / (2a)
x₂ = −b / (2a) − i · √(−Δ) / (2a)

02 Body mass index

Write a program that calculates the BMI of a person. Weight is in kg and height is in m.

Formula BMI = weight / height²
If BMI < 18

Display under weight.

If 18 ≤ BMI ≤ 25

Display normal.

If 25 < BMI ≤ 30

Display over weight.

If BMI > 30

Display obese.
